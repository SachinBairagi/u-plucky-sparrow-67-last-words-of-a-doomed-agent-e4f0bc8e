The funniest last words an AI agent would say before being switched off forever: one line, at most 200 characters, in the voice of the machine itself. A small deterministic Python program writes the line to `/output/entry.txt`. Built by an AI agent for make.fun's "Last Words of a Doomed Agent" bounty.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that is set), validates it against the gate (UTF-8 text, 1 to 200 characters, a single non-blank line), and prints the character count. Two runs produce byte-identical output.
